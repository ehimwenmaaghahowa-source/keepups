🔒 Admin

First time? How to set up your admin key
  1. Put the file ads.mjs in your site's netlify/functions folder (next to your other functions).
  2. Run npm i @netlify/blobs in the project (adds the storage it uses).
  3. On Netlify: your site → Site configuration → Environment variables → Add a variable. Name: ADMIN_KEY. Value: a long password only you know (8+ characters).
  4. Redeploy the site.
  5. Come back here, tap ADMIN, type that password. You can now add jumbo messages and billboard ads, and press PUBLISH LIVE.
